🎮 Что это?
FireLand Launcher — это игровая платформа, которая работает прямо в браузере. Заходишь на сайт, выбираешь игру, играешь. Ничего устанавливать не надо.

С v26.4.0 — FireLand можно скачать как приложение (PWA):

✅ Иконка на рабочем столе

✅ Отдельное окно без браузера

✅ Офлайн-режим

✅ Быстрый запуск

Стек:

Frontend: чистый HTML + CSS + JavaScript (без React/Vue/Svelte)

Сборка: нет (без Webpack/Vite/npm)

Архитектура: 9 модулей + window-гибрид

База данных: Supabase (Postgres + REST + Realtime + Storage)

Хостинг: GitHub Pages

Реалтайм: WebSocket через Supabase Realtime

PWA: Service Worker + Manifest

⚠️ VPN не нужен. Сайт работает в России без VPN.

🛠️ Как это работает?
Архитектура
Браузер открывает index.html, в котором подключены: manifest.json и sw.js (PWA). Дальше подгружаются модули:

storage.js — IndexedDB + save/load + DEFAULT_STATE

games.js — Игры, утилиты, UI игр, меню, таймер

profile.js — Уровни, XP, достижения, кейсы, задания, будильник

sound.js — Звуки и вибрация

streak.js — Стрик, календарь, ежедневная награда, маскот

device.js — Определение устройства, TV, свайпы

script.js — Ядро: темы, настройки, onboarding, init

messenger.js — Чат (Realtime через WebSocket)

leaderboard.js — Топ игроков (REST)

style.css — Стили (темы, адаптив, TV)

Дальше всё общается с Supabase:

chat_messages — общий чат + ЛС + комнаты

chat_reactions — реакции на сообщения

leaderboard — XP и уровни игроков

rooms — глобальные комнаты

Storage — картинки, голосовые, игры

RPC — безопасные операции

Модульная архитектура
FireLand разбит на 9 модулей (вместо одного script.js на 2000 строк):

Файл	Что	Размер
storage.js	IndexedDB + save/load + DEFAULT_STATE	~10 КБ
games.js	Список игр, утилит + UI игр + вкладки	~30 КБ
profile.js	Уровни, XP, достижения, кейсы, задания, будильник	~50 КБ
sound.js	Звуки, вибрация	~4 КБ
streak.js	Стрик, календарь, ежедневная награда, маскот	~6 КБ
device.js	Определение устройства, TV, свайпы	~5 КБ
script.js	Ядро: темы, частицы, часы, настройки, onboarding, init	~15 КБ
messenger.js	Чат (общий, ЛС, комнаты, реакции, медиа)	~75 КБ
leaderboard.js	Топ-100 игроков	~12 КБ
style.css	Стили (темы, адаптив, TV, чат)	~100 КБ
Итого: ~210 КБ кода + 1.5 МБ favicon + 580 КБ маскот.

Гибридный подход:

Модули экспортируют данные в window (window.GAMES, window.ACHIEVEMENTS, ...)

script.js в IIFE (изоляция области видимости)

Совместимость с file:// + http:// + https://

PWA
Service Worker (sw.js) кэширует:

✅ Все модули (CSS, JS)

✅ Маскот (fireek.mp4)

✅ Игры и утилиты (при первом открытии)

✅ Favicon

❌ CDN и Supabase — не кэшируются (данные всегда свежие)

Режимы:

Network-first для HTML (обновления всегда приходят)

Cache-first для остального (мгновенная загрузка)

Stale-while-revalidate (показать старое, обновить в фоне)

Без фреймворков
Весь фронтенд — чистый HTML/CSS/JS. Это значит:

Быстро загружается — нет бандлов по 500 КБ.

Просто хостить — GitHub Pages отдаёт статику.

Легко читать код — открыл DevTools и разобрался.

Realtime через Supabase
Чат работает через WebSocket (Supabase Realtime):

Отправил сообщение → оно в БД.

Supabase пушит событие всем подписчикам.

Все видят сообщение мгновенно.

Онлайн-список работает через Presence — Supabase сам отслеживает, кто подключён.

Глобальные комнаты — подписка на postgres_changes в таблице rooms. Создал комнату → все видят через 1-2 секунды.

Безопасность
owner_token (UUID) — защищает ник от подделки. Хранится в localStorage и БД.

RPC-функции — все изменяющие операции через SECURITY DEFINER:

upsert_score_secure — сохранение XP

rename_nick_everywhere — перенос ника везде

delete_room_secure — удаление комнаты

delete_my_account — удаление аккаунта

RLS-политики + GRANT на всех таблицах.

Sandbox на iframe для игр сообщества.

💾 База данных
Используется Supabase (бесплатный тариф).

Схема:

chat_messages — сообщения чата (общий + ЛС + комнаты)

id BIGSERIAL PRIMARY KEY

room TEXT NOT NULL DEFAULT 'general'

nickname TEXT NOT NULL

text TEXT NOT NULL

reply_to_id BIGINT

image_url TEXT

voice_url TEXT

voice_duration INT DEFAULT 0

created_at TIMESTAMPTZ DEFAULT NOW()

chat_reactions — реакции

id BIGSERIAL PRIMARY KEY

message_id BIGINT NOT NULL

nickname TEXT NOT NULL

emoji TEXT NOT NULL

created_at TIMESTAMPTZ DEFAULT NOW()

UNIQUE (message_id, nickname, emoji)

leaderboard — лидерборд

nickname TEXT PRIMARY KEY

level INT DEFAULT 1

total_xp BIGINT DEFAULT 0

achievements_count INT DEFAULT 0

owner_token TEXT DEFAULT ''

updated_at TIMESTAMPTZ DEFAULT NOW()

rooms — глобальные комнаты

id BIGSERIAL PRIMARY KEY

room TEXT NOT NULL UNIQUE

name TEXT NOT NULL

display TEXT NOT NULL

author_nick TEXT NOT NULL

owner_token TEXT DEFAULT ''

created_at TIMESTAMPTZ DEFAULT NOW()

RLS-политики + GRANT: чтение и запись разрешены роли anon, авторизация — по нику, без пароля.

Realtime: таблицы chat_messages, chat_reactions, rooms добавлены в публикацию supabase_realtime.
